Use cases

Anything that needs “roughly when, agreed by peers” instead of “trust this server’s clock.”

One-time codes

TOTP over Kairos pulse-map median: network t from Subscribe/Get, σ from confidence + staleness, digits from 30s bins. Verify with an independent Get. See OTP / OTP wiki.

Git / forge activity

Stamp tip publishes, registry registrations, or release tags with a Kairos seal so “before / after” is peer-witnessed, not publisher-claimed alone. Soft-host Kairos while browsing (see Hosting).

Rate limits & cooldowns

Contracts that say “once per hour” can key off sealed time rather than each peer’s local clock (which users can wind back).

CRDT / chat ordering assists

Logical clocks stay primary for causality. Kairos helps when you also want a human-facing “sent around 14:02 ± 200 ms” without a central logger.

Notifications & schedules

“Remind after T” and “poll after T” in decentralized apps — using confidence-aware deadlines so early/late nodes don’t thrash.

Audit & disclosure

Seal a document hash when disclosed. Later anyone Gets the sealed stamp and checks the interval (earliest_ms… latest_ms), witness set, and transcript digest — Freenet as the existence surface. Export a notary receipt from a sealed Get.
