Get & Subscribe

There is no special “get time” RPC. You Get (and optionally Subscribe) the Kairos contract key over the Freenet WebSocket. The response is the whole state blob.

State shape (always)

{
{
  "schema_version": 2,
  "roster": { "<node_id>": { first_seen_ms, last_seen_ms, pulse_count, seals_included, seals_outlier } },
  "pulse":  { "<node_id>": { node_id, wall_ms, monotonic_ms, uncertainty_ms, sig } },
  "open_stamps":   { "<hash:nonce>": { …observations… } },
  "sealed_stamps": { "<hash:nonce>": { median, error, earliest, latest, witness_ids, … } }
}

Get is read-only

A Get does not write a pulse. Buttons or helpers labeled Get / “Get pulse median” only read. Pulsing is a separate Update. The current site starts that update automatically through bounded network duty while the page is open; there is no manual Pulse button. Other apps can opt into the same watchNetworkDuty() helper.

If there are no sealed stamps yet

Get still succeeds. You receive roster + pulse (and maybe open requests). That is normal on a young network or a lab that has only been pulsing.

  • Pulse map — latest signed wall times. Client telemetry median ≠ OTP tip (OTP uses a hardened subset; see Trust & security).
  • Roster — who has been pulsing, how long (age), and seal-history counts for reputation.
  • sealed_stamps: {} — nothing to notarize yet. Do not invent a seal from the pulse median.

Subscribe (push)

Freenet Get can register subscribe: true. When the contract updates (e.g. someone pulsed), the gateway sends UpdateNotification on the same WebSocket. Clients refresh state then — no timed Get poll required. Subscriptions are shared at the gateway / connection level: one node can fan out notifications to local apps that subscribed.

The OTP authenticator uses this path. Verify still does an independent Get when you check a code.

Why the median looks NTP-precise

  1. Pulses embed millisecond wall_ms from each peer’s local clock.
  2. The UI formats the median with toISOString().
  3. With one witness, the median is that witness’s last pulse — it jumps when they pulse again with a new wall time.

When you want sealed time

After open_stamp + enough aged observe_stamps, Get the same contract and read sealed_stamps["hash:nonce"]. Widen error with local staleness after your Get (Byztime-style). Details: Notary receipts.
