API surfaces

Contract updates are small JSON deltas over Freenet Update. Reads are Get / Subscribe on the Kairos contract key. Signing prefers the kairos-identity delegate.

1. Pulse (write)

{
{ "pulse": {
    "node_id": "<bs58 ed25519 vk>",
    "wall_ms": 0,
    "monotonic_ms": 0,
    "uncertainty_ms": 40,
    "sig": "<hex>"
} }

Domain kairos.pulse.v1. Keeps the contract hosted and ages the roster. Site helper: submitPulse() (delegate sign + Update). Do not combine with a “Get” button — Get is read-only.

2. Open stamp (write)

{
{ "open_stamp": { "content_hash": "…", "nonce": "unique-per-request" } }

Creates open_stamps["hash:nonce"]. Anyone can open; only aged keys’ observes count toward seal.

3. Observe stamp (write)

{
{ "observe_stamp": {
    "request_id": "hash:nonce",
    "observation": { /* same fields as pulse, domain kairos.stamp.observe.v1 */ }
} }

Rejected if the witness is younger than ~1 hour on the roster. When ≥ min witnesses survive MAD, the request moves to sealed_stamps.

4. Get / Subscribe (read)

Get the contract; inspect pulse / roster / sealed_stamps. With subscribe: true, the gateway pushes UpdateNotification on later Updates — apps re-Get or apply deltas then. See Get & Subscribe.

5. Identity delegate (local)

EnsureIdentity, SignPulse, SignStampObserve (optional Export/Import). Auto-mints a label like kairos-a3f1…. If the delegate is unavailable, the site falls back to a durable browser key. See Identity & age.

6. Network duty (one call — help the oracle)

Separate pulse / observe / Get APIs stay available. For public-goods hosting, apps can use one duty surface that decides what to do from roster age + open stamps — over the same Freenet WebSocket (not a new HTTP endpoint).

  • queryNetworkDuty() — Get + return a plan (no writes).
  • runNetworkDuty() — execute the plan: always pulse (keep-alive / age); if stamp-eligible (~1h), also observe_stamp any open requests you have not signed.
  • watchNetworkDuty() — Subscribe + interval: keep running duty automatically while your app is open.
  • planNetworkDuty(state, identity) — pure helper if you already have state. 
{
// plan shape (kairos.network.duty.v1)
{
  "schema": "kairos.network.duty.v1",
  "stamp_eligible": false,
  "roster_age_ms": 0,
  "min_age_ms": 3600000,
  "open_count": 0,
  "actions": [
    { "type": "pulse", "reason": "…" },
    { "type": "observe_stamp", "request_id": "hash:nonce", "reason": "…" }
  ],
  "summary": "pulse · aging …"
}

Telemetry’s timer/button uses runNetworkDuty(). “Get only” uses queryNetworkDuty() so you can see what help would look like without writing.

Client checklist (app author)

  1. Ensure Kairos contract exists (Put once / Get).
  2. Ensure identity (delegate or local).
  3. Prefer watchNetworkDuty() or runNetworkDuty() on an interval while open — one call covers keep-alive and seal help.
  4. Continuous clock: Subscribe + hardened pulse tip (OTP pattern) — not raw public median. Limits: Trust & security.
  5. Authoritative time for a hash: open → wait for seal → Get sealed entry → build notary receipt.
