Contract schema (draft)

Peers submit signed observations. After quorum, the contract seals an immutable stamp for a request hash.

Parameters

{
"schema": "kairos-time-v1",
"min_witnesses": 7,
"quorum_numerator": 2,
"quorum_denominator": 3,
"max_observation_age_ms": 120000,
"trim_fraction": 0.2

Observation

  • node_id, wall_ms, monotonic_ms, uncertainty_ms, signature
  • One observation per node per open request (latest wins)
  • Reject absurd uncertainty (> 5s)

Seal

  1. Sort wall times; drop trim_fraction tails
  2. Median + MAD; drop points beyond 5×MAD
  3. confidence_ms = error_ms = max(median(uncertainty), 1.4826×MAD, 1)
  4. earliest_ms / latest_ms = median ± error
  5. transcript_digest binds sorted witness lines (accountability)
  6. Freeze stamp under the request id

Full draft with JSON shapes: SCHEMA.md and docs/dependable-time.md in the Kairos repo (not always shipped inside the website contract).
